## 🔍 Quick Troubleshooting

### Can't connect to database?
```bash
✅ MongoDB Atlas is configured in .env.local
✅ Connection string is correct
✅ Network access is allowed in MongoDB Atlas
```

### AI not responding?
```bash
✅ Check API keys are valid
✅ Verify keys have no extra spaces
✅ Ensure billing is enabled (OpenAI)
✅ Check console for error messages
```

### Voice features not working?
```bash
✅ Use Chrome or Edge browser (best support)
✅ Allow microphone permissions
✅ Check volume/audio output
✅ Try on different browser if issues persist
```
