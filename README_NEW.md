## 🌟 Overview

**VaaniAI** is a full-stack AI chatbot platform built for academic projects that showcases modern web development with cutting-edge AI technologies. It features multiple AI personalities, voice input/output, emotion detection, and support for various large language models.

### Key Highlights

- 🗣️ **Full Voice Integration** - Speech-to-text & text-to-speech
- 🎭 **6 Personality Modes** - Professional, Casual, Creative, Friendly, Technical, Humorous
- 🤖 **Multi-LLM Support** - GPT-4, Claude 3, Gemini Pro
- 🧠 **Emotion Detection** - Real-time sentiment analysis
- 🎨 **Modern UI** - Dark/light mode, responsive design
- 🔐 **Secure Auth** - JWT-based authentication system

## 🚀 Quick Start

### Installation

```bash
# 1. Install dependencies (already done)
npm install

# 2. Verify setup
node verify-setup.js

# 3. Start development server
npm run dev

# 4. Open browser
# Visit: http://localhost:3000
```

### Configuration

Your `.env.local` is already configured with:
- ✅ MongoDB Atlas connection
- ✅ JWT secret
- ⚠️ AI API keys needed (add yours)

## 🛠️ Tech Stack

- **Frontend**: Next.js 16, React 19, TailwindCSS 4
- **Backend**: Node.js, MongoDB, Mongoose
- **AI**: OpenAI, Anthropic, Google Gemini
- **Auth**: JWT, bcryptjs
- **Voice**: Web Speech API
